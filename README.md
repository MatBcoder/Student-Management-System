# Student Management System

A Spring Boot REST API for managing student records. This version only uses the basic CRUD operations to manage the data. In memory storage is used and the APIs are tested using Postman.

## Features

* Create Student
* View Students
* Update Student
* Delete Student

## Technologies Used

* Java
* Spring Boot
* Maven
* Postman
* Git
* GitHub

## API Endpoints

### Get All Students

GET /students

### Add Student

POST /students

### Update Student

PUT /students/{id}

### Delete Student

DELETE /students/{id}
